# Especificación de roles (formato Kiro)

`requirements.md`, `design.md` y `tasks.md` siguen la estructura de los specs de Kiro (`.kiro/specs/<feature>/`): historias de usuario con criterios de aceptación en formato EARS, documento de diseño y plan de tareas.

Procedencia: en el entorno donde se resolvió este TP no estaba disponible el IDE Kiro, así que los tres archivos se redactaron directamente en ese formato con asistencia de Claude (registro R1 de `BITACORA.md`). Se escribieron antes que `sql/roles.sql` y son la referencia contra la que se verificaron los permisos. Para regenerarlos en Kiro, crear un spec llamado `food-store-roles` y pegar la introducción de `requirements.md` como descripción de la funcionalidad.
