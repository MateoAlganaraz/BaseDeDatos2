# Reglas del repositorio

## Entregas académicas

- El docente corrige el repositorio de GitHub mediante IA. Por lo tanto, cada trabajo práctico debe quedar autocontenido, verificable y completo en el repositorio.
- La entrega en la plataforma consiste en un único PDF cuyo nombre identifique al repositorio (`DB_Mateo_Algañaraz`). Ese PDF resume la resolución, pero no reemplaza los archivos fuente, scripts SQL, evidencias ni documentación versionados en GitHub.
- Antes de cada `push`, verificar que los artefactos entregables no contengan marcadores como `PENDIENTE`, `TODO`, texto de ejemplo ni resultados inventados. Las conclusiones deben basarse en evidencia reproducible.
- Para cada TP, conservar consultas SQL, variantes para DBeaver cuando correspondan, instrucciones de ejecución, evidencia de resultados y el documento final.
- No incluir en commits directorios temporales de control de calidad, archivos de trabajo intermedios ni credenciales.
